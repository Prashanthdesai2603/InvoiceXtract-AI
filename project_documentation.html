Project Overview

InvoiceXtract AI is a cutting-edge enterprise solution designed to automate the tedious process of manual data entry from financial documents. By leveraging advanced Large Language Models (LLMs) and OCR technologies, the platform transforms unstructured invoice data into structured accounting records with near-perfect accuracy.

Problem It Solves

Traditional accounting involves manual entry of thousands of invoices, which is slow, error-prone, and expensive. Discrepancies in vendor names, taxes, and service descriptions often lead to financial reporting errors.

How AI is Used

The core engine uses Gemini 3 Flash to perform semantic analysis of documents. Unlike template-based solutions, our AI understands context—it can identify "handling charges" as a service and "item price" as a product charge regardless of where they appear on the page.

Real-World Use Case

An accounting firm processing 500+ invoices daily can use InvoiceXtract AI to automatically extract data, validate it against business rules, and instantly create both "Contacts" and "Invoices" in Zoho Books, reducing processing time by 90%.

Folder Structure

Backend Structure

File/Folder Description
main.py The entry point. Initializes FastAPI, connects middlewares (CORS), and mounts all routes.
routes/ Contains API endpoints categorized by feature (e.g., auth_routes.py, invoice_routes.py).
services/ The business logic layer. Includes gemini_service.py (AI prompt logic) and zoho_service.py (API calls).
models/ Database schemas defined using SQLAlchemy ORM (User and Invoice entities).
database/ Connection configuration and session engine for MySQL.
requirements.txt Managed dependency list. Essential for reproducible virtual environments.

Frontend Structure

System Components

  • Presentation Layer: React frontend capturing user input and displaying real-time extraction results.
  • Application Layer: FastAPI handling orchestration, error handling, and file management.
  • Intelligence Layer: Gemini logic that converts image text into structured JSON.
  • Integration Layer: Zoho service module managing OAuth flows and accounting transactions.

Complete Workflow

  1. Upload Invoice: User drags and drops PDF, Image, or Excel file into the dashboard.
  2. File Processing: Backend validates file type and prepares the document for OCR.
  3. AI Extraction: Gemini analyzes the visual layout and text to extract line items, totals, and vendor details.
  4. Data Validation: Backend verifies mandatory fields (Date, Amount, Invoice #) are presence.
  5. Customer Logic: System checks if the vendor exists in Zoho; creates a new contact if not.
  6. Invoice Creation: A draft invoice is generated in Zoho Books with line item breakdowns.
  7. Save to Database: Metadata and processing status are archived in MySQL for historical tracking.
  8. Display in UI: The frontend refreshes to show the extraction summary and Zoho sync status.

How to Setup Project

Backend Setup

1. Ensure Python 3.9+ is installed.

# Go to backend folder
cd backend

# Create virtual environment
python -m venv venv
source venv/Scripts/activate # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Setup .env file
# Copy .env.example to .env and fill in:
# GEMINI_API_KEY, GOOGLE_VISION_KEY, ZOHO_CLIENT_ID, etc.

# Run server
uvicorn main:app --reload

Frontend Setup

1. Ensure Node.js (v16+) is installed.

# Go to frontend folder
cd frontend

# Install dependencies
npm install

# Start development server
npm start

How to Use the Project

1. Authentication

Sign up for an account or login with your credentials to access the secure dashboard.

2. Extraction

Use the 'Upload' area. Once uploaded, the system will show a progress bar during AI analysis.

3. Verification

Review the extracted data in the provided form. Correct any edge cases manually if needed.

4. Zoho Sync

Click 'Save & Sync' to push the data directly into your Zoho Books organization.
